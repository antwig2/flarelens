FlareLens is an **open-source, self-hosted Platform-as-a-Service (BYOC PaaS)** licensed under Apache-2.0. You deploy the serverless control plane in your own Cloudflare account (`Workers + D1 + KV + R2`) and run the lightweight Go host daemon (`flarelensd`) on your own cloud VMs or bare-metal servers.
