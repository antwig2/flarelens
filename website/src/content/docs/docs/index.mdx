**Your infrastructure. One control plane.** Deploy, manage, secure, and monitor applications across cloud and on-premises servers. FlareLens brings infrastructure operations together in an open-source, self-hosted platform (Apache-2.0)—deploying the serverless control plane in your own Cloudflare account (`Workers + D1 + KV + R2`) and running the lightweight Go host daemon (`flarelensd`) on your own servers, without the complexity of Kubernetes or a dedicated management server.

## Core Platform Capabilities

Six integrated capabilities for operating cloud VMs and on-premises servers from one control plane.

<CardGrid>
  <Card title="Fleet Management" icon="ph:hard-drives" href="/docs/fleet/">
    Register and manage cloud VMs and physical servers from one dashboard. Schedule workloads across machines, control CPU and memory allocation, and perform server maintenance.
  </Card>
  <Card title="Application Deployments" icon="ph:arrows-clockwise" href="/docs/deployments/">
    Deploy Docker applications, manage immutable revisions, promote changes between environments, perform Blue/Green releases, and roll back failed deployments without requiring Kubernetes.
  </Card>
  <Card title="Private Mesh Networking" icon="ph:share-network" href="/docs/mesh/">
    Connect servers and operator devices across different networks using WireGuard, encrypted peer-to-peer communication, and private service discovery.
  </Card>
  <Card title="Observability" icon="ph:chart-line-up" href="/docs/observability/">
    Monitor server health, resource usage, containers, and application logs. Store logs in Cloudflare R2 using Parquet and query them through DuckDB.
  </Card>
  <Card title="Secrets & Feature Flags" icon="ph:key" href="/docs/secrets-and-flags/">
    Manage encrypted application secrets and runtime configuration centrally, alongside feature flags that control application behavior.
  </Card>
  <Card title="Backups & Recovery" icon="ph:database" href="/docs/backups/">
    Stream PostgreSQL backups to R2, schedule backups, protect database migrations, and support restoration.
  </Card>
</CardGrid>
