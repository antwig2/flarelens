🔗 GitHub & CI/CD Webhook GitOps

Every time a new Docker image is published to GitHub Container Registry (GHCR) or a commit is pushed to main, FlareLens can automatically execute zero-downtime blue/green rollouts across your fleet with Vault secret injection.

Webhook URL https://control.example.com/api/v1/control/deploy/webhook
Content type: application/json Secret: WEBHOOK_SECRET Events: Pushes, Packages
GitHub Actions Workflow Snippet 
- name: Trigger FlareLens GitOps Blue/Green Deploy
  run: |
    curl -X POST https://control.example.com/api/v1/control/deploy/webhook \
      -H "Content-Type: application/json" \
      -d '{
        "service": "bill-api",
        "image": "ghcr.io/my-org/bill-api:${{ github.sha }}",
        "node_id": "all-prod"
      }'
